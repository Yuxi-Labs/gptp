# Input Files

Each `.input.json` file provides values for a corresponding `.gptp` prompt.

- `artist-statement.input.json` – For generating a poetic artist bio
- `brand-tagline.input.json` – For tagline writing
- `resume-writer.input.json` – For resume summaries
- `test-prompt.input.json` – General-purpose values used to test tooling

Inputs are structured as key-value pairs matching `{{variables}}` in the prompt template.
